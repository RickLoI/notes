    All good computer scientists know that a lot, 
        if not all, problems in the field can be regarded as optimization problems.
        From calculus, the optimization of a continous function $f(x)$,
        subject to the constrain functions $g(x), h(x)$,
        consists in finding $x$, such that $g(x) \text{ and } h(x)$ hold,
        and $f(x)$ is a minimum (or a maximum).

    As we will see later, we can have \emph{local} and \emph{global} optimum.
        In the first case, the the solution is optimum with respect to a restricted neighborhood;
        viceversa, a global optimum represents the best possible solution.
